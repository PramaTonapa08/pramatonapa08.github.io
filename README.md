
# Prama Hardi Tonapa — Personal Portfolio

## Deskripsi Situs

Website ini merupakan portofolio pribadi milik **Prama Hardi Tonapa**, atau biasa dipanggil Rama. Saya merupakan mahasiswa tahun pertama Program Studi Statistika, Fakultas Matematika dan Ilmu Pengetahuan Alam, Universitas Cenderawasih.

Portofolio ini dibuat sebagai tempat untuk memperkenalkan diri, menampilkan berbagai proyek yang pernah dikerjakan, serta membagikan pemikiran, ide, dan pengalaman selama proses belajar. Website ini dibangun menggunakan **Astro** dan **Tailwind CSS**, dengan tampilan retro-tech yang telah disesuaikan dengan gaya dan preferensi pribadi.

**Kunjungi Website:** [pramatonapa08.github.io](https://pramatonapa08.github.io)

## Fitur

Beberapa fitur yang tersedia dalam website ini antara lain:

- **Halaman Beranda:** Menampilkan perkenalan singkat dan informasi utama tentang diri saya.
- **Halaman Proyek:** Menampilkan kumpulan proyek, hasil eksperimen, dan hal-hal yang pernah saya kerjakan.
- **Halaman Tentang:** Berisi informasi mengenai latar belakang, pendidikan, pengalaman, dan minat pribadi.
- **Halaman Blog:** Tempat berbagi pemikiran, ide, dan pengalaman selama proses belajar.
- **Halaman Artikel:** Menampilkan isi lengkap dari setiap tulisan atau artikel.
- **Halaman Kontak:** Menyediakan informasi dan tautan untuk menghubungi saya.
- **Desain Responsif:** Tampilan website dapat menyesuaikan berbagai ukuran layar, baik komputer maupun perangkat seluler.
- **Navigasi Pagination:** Memudahkan pengunjung menjelajahi daftar proyek dan artikel.
- **SEO dan Sitemap:** Membantu mesin pencari mengenali dan mengindeks halaman website.
- **Custom Styling:** Tampilan, warna, tipografi, dan beberapa komponen telah disesuaikan dengan preferensi pribadi.

## Cara Menjalankan Secara Lokal

Untuk menjalankan website ini di komputer sendiri, pastikan **Node.js**, **npm**, dan **Git** sudah terpasang.

**1. Clone repository**

Buka terminal, kemudian jalankan perintah berikut:

```bash
git clone https://github.com/PramaTonapa08/pramatonapa08.github.io.git
```

**2. Masuk ke direktori proyek**

```bash
cd pramatonapa08.github.io
```

**3. Instal dependensi**

```bash
npm install
```

**4. Jalankan server pengembangan**

```bash
npm run dev
```

**5. Buka website di browser**

Setelah server berhasil dijalankan, buka alamat berikut:

```text
http://localhost:4321
```

Website sekarang dapat diakses secara lokal dan perubahan pada kode dapat langsung dilihat melalui browser.

## Perintah Astro

Beberapa perintah yang dapat digunakan selama pengembangan website:

| Perintah | Fungsi |
|---|---|
| `npm install` | Menginstal seluruh dependensi proyek. |
| `npm run dev` | Menjalankan server pengembangan lokal. |
| `npm run build` | Membuat versi produksi website. |
| `npm run preview` | Melihat hasil build secara lokal. |
| `npm run astro -- --help` | Menampilkan bantuan perintah Astro. |
